# DSA210 Project

## Overview
This project is designed as part of the DSA210 course, focusing on data structures and algorithms. The goal is to provide a comprehensive understanding of various algorithmic techniques and data structures while implementing them in practical scenarios.

## Features
- **Data Structures Implementation**: Includes linked lists, stacks, queues, trees, and graphs.
- **Algorithm Analysis**: Implementation and comparison of sorting and searching algorithms.
- **Visualization**: Basic tools for visualizing different algorithms in action.
- **Tests and Benchmarking**: Includes unit tests for various components to ensure correctness and performance metrics.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/zainabsiddiqui12/DSA210-Project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd DSA210-Project
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
To run the project, execute the main script:
```bash
python main.py
```

You can unleash different functionalities by following the provided instructions in the usage section of the specific modules.
